One structure in both modes

Main runs advance downward. Branch connectors and indentation distinguish children even without color or titles. Compact mode retains one bar per task.

History stays nearby

Completed main runs become short summaries, not full-height cards. Select and press D for the original note ledger.

No aggregate percentage

Each agent owns its own estimate. The chat heading counts running work, without inventing a combined progress value.

Reading order: main 1 → main 2 → main 3 → child A → child B → unrelated chat. Old main runs remain immediately above the newer main run; children never masquerade as followups.

Static design study. Chat labels are illustrative; current metadata has no chat title. Production can use project plus a stable chat symbol or short thread ID until an optional display title exists. Hover labels shown through native browser tooltips.
